# 英検スコア管理（eiken-score-management）

英検の勉強をしていたときに作った、スコアを記録してグラフで見るためのツールです。

👉 使う: https://yamasho0419.github.io/eiken-score-management/

## 作った理由

どの技能にどれくらい勉強時間をかけるのがよいかを、自分のスコアから判断したいと思いました。
回ごとの正答率をグラフにして、伸びている技能と足りない技能をひと目で分かるようにしました。

## できること

- 回ごとのスコア（リーディング・リスニング・ライティング）の入力と一覧表示
- 正答率の計算
- リーディングとリスニングの正答率の推移をグラフで表示（目安の70%に線を引く）
- 記録はブラウザ内（localStorage）に保存し、CSV でダウンロードできる

## 技術

HTML / JavaScript（1ファイル）、Plotly（グラフ）、FileSaver.js（CSV の保存）
